# Plant Disease Classifier

A final-year group project that uses TensorFlow and ResNet50V2 to classify plant leaf images.

## Model and results

We trained an ImageNet-pretrained ResNet50V2 model using 160 × 160 RGB images. The model achieved **96.50% accuracy on the dataset's test split**.
